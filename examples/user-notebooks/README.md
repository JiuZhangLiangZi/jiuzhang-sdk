# Jiuzhang SDK User Notebooks

This directory contains Jupyter notebooks prepared for Jiuzhang SDK users.

## Files

- `sdk_usage.ipynb`: cloud platform GBS task workflow.
- `sdk_local_usage.ipynb`: local GBS math, sampling, and result analysis workflow.
- `mnist_recognition_zh.ipynb`: MNIST recognition workflow using local SDK application APIs.
- `dense_subgraph_zh.ipynb`: dense subgraph workflow using local SDK application APIs.
- `graph_isomorphism_zh.ipynb`: graph isomorphism workflow using local SDK application APIs.
- `molecular_docking_zh.ipynb`: molecular docking workflow using local SDK application APIs.
- `molecular_vibronic_spectra_zh.ipynb`: molecular vibronic spectra workflow using local SDK application APIs.

The `.npy` files are sample datasets used by the local application notebooks.
